# Roliga Nodes

Collection of roliga (Swedish for "fun") and helpful nodes for [Godot Engine](https://godotengine.org).

Meant to make working with nodes in Godot even more fun, inspiring, and easy.


## Version

Roliga Nodes **requires at least Godot 4.7**.


## Installation

* Download the archive.
* Extract the `addons` folder, it contains `Roliga Nodes`.
* Move the `addons` folder to your `Roliga Nodes` project folder.
* Activate the plugin inside Godot.

It is possible to just download the node or nodes you want and place them directly inside your project folder.


## Nodes


### bool_node.gd

Node with a bool.


### color_node.gd

Node with a color. Can also randomize a color.


### counter_node.gd

Counter with add and subtract.


### destroy_target.gd

Assign a target and destroy it on command.


### file_access_node.gd

Read and write text to a file.


### float_node.gd

Node with a float.


### hide_parent_on_ready.gd

Hide parent node if possible when _ready() is called.


### int_node.gd

Node with an int.


### on_off_node.gd

On and off functions. Used to represent an on/off state.


### open_close_node.gd

Open and close functions. Used to represent an open/close state.


### pair_node.gd

Link a pair of nodes and make them work as a pair.


### show_parent_on_ready.gd

Show parent node if possible when _ready() is called.


### spawn_scene_node.gd

Spawn a PackedScene as child or as child to a target node.


### string_node.gd

Node with a string.
